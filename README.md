# Evolution API – Deploy no Render

Este repositório contém apenas a **estrutura necessária** para subir a Evolution API REAL no Render.

## Passos

1. Faça um fork deste repositório para sua conta do GitHub.
2. No Render, clique em **New → Web Service** e selecione este repositório.
3. Configure as variáveis de ambiente conforme o arquivo `.env.example`.
4. Deploy e pronto.

## Código da Evolution API
O código real será clonado automaticamente através do Dockerfile deste repo.
